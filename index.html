Packet Sniffing & Network Traffic Analysis
tcpdump · Wireshark · HTTP · Kali Linux
▾
Objective

Capture live network packets, analyze them, and understand what information an attacker can observe. Since HTTP is unencrypted, all transmitted data is visible in plain text to anyone capturing the traffic.

Requirements
Kali Linux (VirtualBox) Wireshark (built-in) Python HTTP Server tcpdump Firefox
Procedure
  • 01Open Kali Linux in Oracle VirtualBox and launch the terminal.
  • 02Open a terminal and start a local HTTP server on port 8080:
    python3 -m http.server 8080
  • 03Open a second terminal and start packet capture, saving to a file:
    sudo tcpdump -i any -w capture.pcap port 8080
  • 04Open Firefox and navigate to http://localhost:8080. Refresh the page several times to generate traffic.
  • 05Return to the tcpdump terminal and press Ctrl + C to stop capture. The packets are saved as capture.pcap.
  • 06Open File Manager → locate capture.pcap in the Home folder → double-click to open in Wireshark.
  • 07In Wireshark's filter bar, type http.request.method == "POST" and press Enter to isolate login packets.
  • 08Click on any packet to inspect its payload. Browser details, OS info, and any form-submitted credentials appear in plain text.
Conclusion

Packets were successfully captured and analyzed. Sensitive data is fully visible when HTTP is used. Packet sniffing demonstrates that unencrypted communication is unsafe — HTTPS is necessary to protect data in transit.

Password Strength Testing
Python · Regex · Input Validation
▾
Objective

Write a Python program that evaluates a password as Weak, Medium, or Strong based on length, digit, case, and special-character rules.

Rules
  • R1Minimum 8 characters in length
  • R2At least one digit (0–9)
  • R3At least one uppercase letter
  • R4At least one lowercase letter
  • R5At least one special character (e.g. !@#$%^&*())
Program — password_checker.py
import re

def check_password_strength(password):
    if len(password) < 8:
        return "Weak: Password must be at least 8 characters long."
    if not any(char.isdigit() for char in password):
        return "Weak: Password must include at least one number."
    if not any(char.isupper() for char in password):
        return "Weak: Password must include at least one uppercase letter."
    if not any(char.islower() for char in password):
        return "Weak: Password must include at least one lowercase letter."
    if not re.search(r'[!@#$%^&*(),.?":{}|<>]', password):
        return "Medium: Add special characters to make your password stronger."
    return "Strong: Your password is secure!"

def password_checker():
    print("Welcome to the Password Strength Checker!")
    while True:
        password = input("\nEnter your password (or type 'exit' to quit): ")
        if password.lower() == "exit":
            print("Goodbye!")
            break
        print(check_password_strength(password))

if __name__ == "__main__":
    password_checker()
Sample Output

→ Weak: Password must be at least 8 characters long.

Enter your password: Abcdef12
→ Medium: Add special characters to make your password stronger.

Enter your password: Abc@1234
→ Strong: Your password is secure!
Execution Steps
  • 01Open Command Prompt or VS Code Terminal.
  • 02Navigate to the folder: cd path\to\folder
  • 03Run: python password_checker.py
  • 04Enter passwords to test. Type exit to quit.

Requirements
Python 3.x Windows OS PowerShell VS Code / Any IDE Internet Connection
Part A — Manual Firewall Rule (GUI)
  • 01Open Windows Defender Firewall with Advanced Security.
  • 02Click Inbound Rules → New Rule in the right panel.
  • 03Select Custom → All Programs → default Protocol & Ports → click Next.
  • 04Under Scope → Remote IP address, select "These IP addresses" → Add the IP (e.g. 1.2.3.4) → OK → Next.
  • 05Action: Block the connection → Profile: Domain, Private, Public → Name: Manual_Block_IP → Finish.
Part B — Automated Script (firewall.py)
import requests, csv, subprocess

# Source: Abuse CH IP blocklist
response = requests.get(
    "https://feodotracker.abuse.ch/downloads/ipblocklist.csv"
).text

# Remove any existing BadIP rules
rule = 'netsh advfirewall firewall delete rule name="BadIP"'
subprocess.run(["PowerShell", "-Command", rule])

mycsv = csv.reader(
    filter(lambda x: not x.startswith("#"), response.splitlines())
)

for row in mycsv:
    ip = row[1]
    if ip != "dst_ip":
        print("Added Rule to block:", ip)
        rule = (
            "netsh advfirewall firewall add rule name='BadIP' "
            "Dir=Out Action=Block RemoteIP=" + ip
        )
        subprocess.run(["PowerShell", "-Command", rule])

Added Rule to block: 103.17.48.5
Added Rule to block: 185.234.219.12
