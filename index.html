🧪 Experiment 2 — Page Title Verification

Objective: Verify that Google's title matches "Google".

Concepts

WebDriver · ChromeDriver · driver.get() · driver.getTitle() · expected vs actual · PASS/FAIL

Complete code

package com.test.sel; import org.openqa.selenium.WebDriver; import org.openqa.selenium.chrome.ChromeDriver; public class Exp2 { public static void main(String[] args) throws InterruptedException { WebDriver driver = new ChromeDriver(); driver.get("https://www.google.com"); String expectedTitle = "Google"; String actualTitle = driver.getTitle(); System.out.println("Actual Title : " + actualTitle); System.out.println("Expected Title : " + expectedTitle); if (actualTitle.equals(expectedTitle)) { System.out.println("PASS: Title is correct"); } else { System.out.println("FAIL: Title is incorrect"); } Thread.sleep(2000); driver.quit(); } }

Explanation

WebDriver driver = new ChromeDriver(); — browser-control object.
driver.get("...") — navigates to URL.
driver.getTitle() — returns page title.
actualTitle.equals(expectedTitle) — assertion logic.

Expected output

Actual Title : Google Expected Title : Google PASS: Title is correct

Execution

mvn compile mvn exec:java -Dexec.mainClass="com.test.sel.Exp2"

🧪 Experiment 3 — Web Element Validation

Objective: Verify Google search box is displayed and enabled.

Concepts

WebElement · By · findElement() · By.name() · isDisplayed() · isEnabled()

Complete code

package com.test.sel; import org.openqa.selenium.By; import org.openqa.selenium.WebDriver; import org.openqa.selenium.WebElement; import org.openqa.selenium.chrome.ChromeDriver; public class Exp3 { public static void main(String[] args) { WebDriver driver = new ChromeDriver(); driver.get("https://www.google.com"); WebElement searchBox = driver.findElement(By.name("q")); System.out.println("Displayed : " + searchBox.isDisplayed()); System.out.println("Enabled : " + searchBox.isEnabled()); if (searchBox.isDisplayed() && searchBox.isEnabled()) { System.out.println("PASS: Search box is ready"); } else { System.out.println("FAIL: Search box is not ready"); } driver.quit(); } }

Explanation

driver.findElement(By.name("q")) — finds element with name="q".
isDisplayed() — visibility. isEnabled() — interactable.
If locator not found → NoSuchElementException.

Expected output

Displayed : true Enabled : true PASS: Search box is ready

🧪 Experiment 4A — Element Screenshot & Bitmap Checkpoint

Objective: Capture search box screenshot and compare pixel-by-pixel with baseline.

Concepts

getScreenshotAs() · OutputType.FILE · BufferedImage · getRGB() · visual regression

Complete code (Exp4.java)

package com.test.sel; import java.awt.image.BufferedImage; import java.io.File; import javax.imageio.ImageIO; import org.openqa.selenium.By; import org.openqa.selenium.OutputType; import org.openqa.selenium.WebDriver; import org.openqa.selenium.WebElement; import org.openqa.selenium.chrome.ChromeDriver; import org.openqa.selenium.io.FileHandler; public class Exp4 { public static void main(String[] args) throws Exception { WebDriver driver = new ChromeDriver(); driver.get("https://www.google.com"); WebElement searchBox = driver.findElement(By.name("q")); File folder = new File("Screenshots"); if (!folder.exists()) folder.mkdir(); File current = new File("Screenshots/current_searchbox.png"); FileHandler.copy(searchBox.getScreenshotAs(OutputType.FILE), current); File baseline = new File("Screenshots/baseline_searchbox.png"); if (!baseline.exists()) { System.out.println("Baseline image not found."); System.out.println("Rename current_searchbox.png to baseline_searchbox.png"); } else { BufferedImage img1 = ImageIO.read(baseline); BufferedImage img2 = ImageIO.read(current); if (img1.getWidth() == img2.getWidth() && img1.getHeight() == img2.getHeight()) { boolean same = true; for (int x = 0; x < img1.getWidth(); x++) { for (int y = 0; y < img1.getHeight(); y++) { if (img1.getRGB(x, y) != img2.getRGB(x, y)) { same = false; break; } } } System.out.println(same ? "BITMAP CHECKPOINT : TEST PASS" : "BITMAP CHECKPOINT : TEST FAIL"); } else { System.out.println("BITMAP CHECKPOINT : TEST FAIL"); } } driver.quit(); } }

Algorithm

Baseline ↔ Current → check dimensions → loop every pixel → compare RGB → all equal ? PASS : FAIL

getRGB(x,y) returns pixel color. Even tiny difference → FAIL (exact equality).

🧪 Experiment 4B — Screenshot Similarity

Objective: Capture browser area, calculate percentage of identical pixels vs baseline.

Concepts

TakesScreenshot · getSubimage() · similarity = (identical pixels / total) × 100

Complete code (Exp4b.java)

package com.test.sel; import java.awt.image.BufferedImage; import java.io.File; import javax.imageio.ImageIO; import org.openqa.selenium.OutputType; import org.openqa.selenium.TakesScreenshot; import org.openqa.selenium.WebDriver; import org.openqa.selenium.chrome.ChromeDriver; public class Exp4b { public static void main(String[] args) throws Exception { WebDriver driver = new ChromeDriver(); driver.manage().window().maximize(); driver.get("https://www.google.com"); File screenshot = ((TakesScreenshot) driver).getScreenshotAs(OutputType.FILE); BufferedImage fullImage = ImageIO.read(screenshot); File folder = new File("Screenshots"); if (!folder.exists()) folder.mkdir(); int width = Math.min(800, fullImage.getWidth()); int height = Math.min(600, fullImage.getHeight()); BufferedImage currentArea = fullImage.getSubimage(0, 0, width, height); File currentFile = new File("Screenshots/current_google_area.png"); ImageIO.write(currentArea, "png", currentFile); System.out.println("Current screenshot saved."); File baselineFile = new File("Screenshots/baseline_google_area.png"); if (!baselineFile.exists()) { System.out.println("Baseline image not found."); System.out.println("Rename current_google_area.png to baseline_google_area.png"); } else { BufferedImage baseline = ImageIO.read(baselineFile); double similarity = compareImages(baseline, currentArea); System.out.println("Similarity : " + similarity + "%"); if (similarity >= 95) { System.out.println("BITMAP CHECKPOINT : TEST PASS"); } else { System.out.println("BITMAP CHECKPOINT : TEST FAIL"); } } driver.quit(); } public static double compareImages(BufferedImage img1, BufferedImage img2) { if (img1.getWidth() != img2.getWidth() || img1.getHeight() != img2.getHeight()) { return 0; } long totalPixels = (long) img1.getWidth() * img1.getHeight(); long samePixels = 0; for (int x = 0; x < img1.getWidth(); x++) { for (int y = 0; y < img1.getHeight(); y++) { if (img1.getRGB(x, y) == img2.getRGB(x, y)) { samePixels++; } } } return (samePixels * 100.0) / totalPixels; } }

Threshold 95% — more tolerant than exact bitmap equality.

🧪 Experiment 5 — Database Testing (H2)

Objective: Create table, insert student, retrieve and verify.

Concepts

JDBC · H2 · DriverManager · Connection · Statement · ResultSet

Complete code

package com.test.sel; import java.sql.Connection; import java.sql.DriverManager; import java.sql.ResultSet; import java.sql.Statement; public class Exp5 { public static void main(String[] args) { try { Connection con = DriverManager.getConnection("jdbc:h2:./StudentDB", "sa", ""); Statement stmt = con.createStatement(); stmt.execute("CREATE TABLE IF NOT EXISTS STUDENT(ID INT PRIMARY KEY, NAME VARCHAR(50), EMAIL VARCHAR(100))"); stmt.execute("DELETE FROM STUDENT"); stmt.executeUpdate("INSERT INTO STUDENT VALUES(1,'Ajay','ajay@gmail.com')"); ResultSet rs = stmt.executeQuery("SELECT * FROM STUDENT WHERE ID = 1"); if (rs.next()) { System.out.println("Record Exists"); System.out.println("ID : " + rs.getInt("ID")); System.out.println("Name : " + rs.getString("NAME")); System.out.println("Email : " + rs.getString("EMAIL")); System.out.println("TEST PASSED"); } else { System.out.println("Record Not Found"); System.out.println("TEST FAILED"); } con.close(); } catch (Exception e) { e.printStackTrace(); } } }

JDBC pipeline

Java → DriverManager → Connection → Statement → SQL → H2 → ResultSet → verification

execute() (DDL) · executeUpdate() (INSERT/UPDATE) · executeQuery() (SELECT) · rs.next() moves cursor.

🎤 Viva Questions

What is Selenium?
A framework for automating web browsers.
What is WebDriver?
Core interface for browser automation.
What is ChromeDriver?
WebDriver implementation for Chrome.
What is Selenium Manager?
Auto-manages driver executables.
What does driver.get() do?
Navigates to a URL.
Difference between isDisplayed() and isEnabled()?
isDisplayed() checks visibility; isEnabled() checks interactability.
What happens if findElement() cannot find an element?
Throws NoSuchElementException.
What is bitmap comparison?
Pixel-by-pixel image comparison.
Why use 95% similarity in Exp4b?
Tolerance for minor rendering differences.
What is JDBC?
Java API for database connectivity.
Difference between execute(), executeUpdate(), executeQuery()?
execute() general; executeUpdate() for DML; executeQuery() for SELECT.
What does rs.next() do?
Moves cursor to next row, returns true if exists.
